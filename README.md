# Go Stand Up 
A basic extension to remind you to stand up once in a while when you work on a computer for long hours

Why ? Just to build a random extension

## To run it locally
- Download the project
- Go to chrome://extensions/ and switch to developer mode
- Click on the button "Pack an unpacked extension" and choose the project in your files
- And test it
